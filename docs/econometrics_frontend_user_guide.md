# Econometrics Frontend User Guide

Open **Content Econometrics QA**, then choose **Econometrics**.

## Research Overview

Start with the sample cards and permanent scope statement. Use the feature scorecard to compare support, raw differences, G1/G2 associations, domain-FE sensitivity, interval width, robustness, and model readiness. A blank estimate means that model was not available for that feature.

## Feature Explorer

Choose one feature at the top. Read the feature definition and measurement warnings first. Then move through:

1. unadjusted cited-rate evidence;
2. G1/G2 headline estimates and the cross-model path;
3. predefined transition cards, largest sensitivity, and covariance sensitivity;
4. subgroup descriptions;
5. website examples and comparable pages;
6. related features, multicollinearity, confounding, and evidence quality;
7. sample flow and the technical appendix.

The example filters affect only precomputed descriptive evidence. They do not refit or filter the fixed-effect models. When support is too small or a model is absent, the app says so.

## Reading Estimates

`+3.1 pp` means an estimated 3.1 percentage-point difference for the displayed contrast in that model. Always read its confidence interval, sample size, model role, and sensitivity path. It is an association among surfaced sources, not an expected gain from changing a webpage.

Use **Point estimate versus uncertainty** to see whether clustering changes only interval width or also zero inclusion. Use **Specification versus sample change** before attributing a transition to fixed effects or controls. Missing aliases are displayed and never synthesized.
