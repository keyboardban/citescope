# Frontend Model Comparison Guide

## Model Path

Choose a feature and, for categorical features, an exact contrast. The forest plot displays every available precomputed G1–G8 estimate in harmonized percentage-point units. G1 and G2 are headline models. Source model IDs distinguish multiple G8 treatments.

## What changed between models?

Select a predefined transition. The card shows coefficient change, interval-width change, row change, comparability, and whether controls, fixed effects, sample, or functional form changed.

## Largest sensitivity

This panel identifies the largest meaningful compatible transition. It is not a model-selection recommendation.

## Point estimate versus uncertainty

Choose one specification to compare covariance estimators. The coefficient should remain fixed while intervals change. Unavailable two-way covariance remains visible in the technical artifact with its warning.

## Intent interactions

Page length and table presence have supported intent-specific slopes. These do not constitute pairwise intent differences because the required contrast covariance was not exported.

## Technical details

Expand the technical section for formulas, exact p-values, covariance estimators, fixed effects, controls, reference groups, samples, clusters, taxonomy versions, and warnings. The raw table is deliberately not the first view.

## Interpretation boundary

All results are conditional associations among surfaced sources. Do not interpret a positive estimate as an expected gain from editing content, a causal effect, or a web-wide citation probability.
